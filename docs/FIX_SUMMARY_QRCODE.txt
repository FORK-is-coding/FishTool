问题：导航页生成二维码失败
错误：'bytes' object has no attribute 'save'

根因：
  desktop/welcome_wizard.py 错误地将 bytes 当作 PIL Image 处理

修复：
  ✅ 修改文件: desktop/welcome_wizard.py (第 95-106 行)
  ✅ 删除冗余代码: 6 行
  ✅ 直接使用 QImage.loadFromData(bytes)

修复前代码:
  ```python
  img = qr_img  # 错误：假设是 PIL Image
  buffer = BytesIO()
  img.save(buffer, format='PNG')  # ❌ bytes 没有 save 方法
  buffer.seek(0)
  qimage = QImage()
  qimage.loadFromData(buffer.read())
  ```

修复后代码:
  ```python
  # qr_img 是 bytes 类型，直接使用
  qimage = QImage()
  qimage.loadFromData(qr_img)  # ✅ 直接加载 bytes
  ```
