AI配置教程

以 DeepSeek 为例，三步完成配置，无需编程基础。

API是什么

API 可以理解为工具箱和 DeepSeek 之间的专用通道。工具箱通过它把分析需求交给模型，再把结果展示给你。

01

申请 API Key

访问 DeepSeek 开放平台，注册并登录账号，在“API Keys”中创建一枚新密钥。

02

填入配置页

把密钥填入下方 API Key；Base URL 填写 https://api.deepseek.com。

03

选择模型

从模型列表选择 deepseek-chat，再点击“保存配置”。

API如何配置

按上方顺序填好三个字段即可。保存后，热点选题、UP主拆解等 AI 功能会使用你选择的模型。

!

API Key 相当于账号密码
请只填写在自己的工具箱中，不要截图、转发或提供给他人。
